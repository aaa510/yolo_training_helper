# YOLO训练助手

## 项目简介
YOLO训练助手是一个基于PyQt5开发的图形界面工具，用于简化YOLOv5模型的训练过程。通过友好的图形界面，用户可以轻松配置训练参数、管理数据集类别，并实时监控训练进度。

## 功能特性

### 1. 数据集管理
- **选择数据集目录**：通过文件夹选择对话框指定数据集位置
- **类别管理**：支持动态添加/删除训练类别
- **自动生成YAML配置**：根据用户输入自动生成YOLOv5所需的data配置文件

### 2. 训练参数配置
- **模型选择**：支持多种预训练模型（yolov5s, yolov5m, yolov5l, yolov5x等）
- **训练参数设置**：
  - Batch Size设置
  - 图像大小调整
  - 训练轮数(Epochs)
  - 优化器选择
  - 超参数配置文件选择
  - 工作线程数设置
  - 项目保存路径
  - 实验名称设置
- **矩形训练**：支持启用/禁用矩形训练选项

### 3. 训练监控
- **命令预览**：实时显示生成的训练命令
- **训练日志**：实时显示训练过程中的输出信息
- **ANSI转义处理**：自动过滤训练日志中的ANSI颜色代码

### 4. 辅助功能
- **帮助对话框**：提供使用指南和帮助信息

- Python 3.7+
- PyQt5
- YOLOv5（需单独克隆）
